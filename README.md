# Linux System Checker

A basic Bash script for Linux environments that displays system uptime, checks disk space usage, and appends time-stamped status logs to a file.

## Features
- **Uptime Monitoring:** Displays current system load and runtime.
- **Disk Space Check:** Inspects root filesystem utilization.
- **Automated Logging:** Appends check results to `system_status.log`.

## Tech Stack
- **Language:** Bash Scripting
- **OS:** Linux / Unix

## How to Run
```bash
chmod +x check_system.sh
./check_system.sh
